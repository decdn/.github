# deCDN

**[Website](https://decdn.org)** · **[Docs](https://docs.decdn.org)** · **[Network stats](https://stats.decdn.org)** · **[Discord](https://discord.gg/vVbNswKVGX)** · **[X](https://x.com/decdn_)**

A decentralized CDN where nodes bond stake, cache content-addressed blobs, and earn per-MB USDC payments through off-chain vouchers backed by a shared on-chain pool ([ADR 003](https://github.com/decdn/decdn/blob/main/adr/003-payments.md)). Built in Rust on [iroh](https://github.com/n0-computer/iroh) QUIC. Open source under MIT OR Apache-2.0.

> **Status: public testnet** ([launch post](https://decdn.org/blog/testnet-is-live/)). The network runs on Arbitrum Sepolia; production targets Arbitrum One. Content is addressed by `decdn:` URIs: `decdn quote <uri>` prices a pull before any paid byte, `decdn get <uri>` downloads and verifies a file or a whole bundle and ends with a verifiable pull receipt, `decdn gateway` serves the same URIs to a local browser (or to anyone, from its own pool, with `--public-url`), and `decdn self-update` moves an installed binary to the latest signed release. A sponsor can pay for the transfer, so a one-line installer is enough to try it with no wallet, keys, or account ([quickstart](https://github.com/decdn/decdn#readme)). Signed binaries, crates (including the [`decdn-client`](https://crates.io/crates/decdn-client) SDK), and container images for the `decdn-node` daemon, the `decdn` CLI, and the `sponsord` daemon and its onramp ship with each [release](https://github.com/decdn/decdn/releases/latest); install them with the one-liner, `cargo binstall`, or `docker pull`. Wire, ABI, config, and storage formats change without compatibility shims until mainnet, and many ADRs are still Draft. The [ADRs](https://github.com/decdn/decdn/tree/main/adr) are the source of truth for current thinking.

## The repos

- **[decdn/decdn](https://github.com/decdn/decdn)**: the core Rust monorepo. A Cargo workspace with the `decdn-node` daemon and `decdn` CLI, plus crates for the protocol, cache, client, incentive, and reputation layers. It also holds [sponsord](https://github.com/decdn/decdn/blob/main/docs/sponsord/README.md), the sponsorship daemon and onramp behind sponsored downloads: a publisher funds a USDC payment pool, and their users download any `decdn:` URI through a one-line installer and a captcha, with no wallet, keys, or tokens to manage (merged from the separate `decdn/sponsord` repo, now archived, and released with the rest of the workspace from v0.3.0). The Solidity contracts and the ADRs behind the design live here too. Most work happens here.
- **[decdn/sdk-typescript](https://github.com/decdn/sdk-typescript)**: [`@decdn/client`](https://www.npmjs.com/package/@decdn/client), the TypeScript client for Node.js and browsers. It speaks HTTP to a `decdn gateway` and hashes every whole blob again with BLAKE3 as it streams, covering bundles, byte ranges, pages on a bundle's site origin, loopback capabilities, and namespace pointers, with no native code, iroh, or wallet library. Its contract suite runs against released `decdn` gateways.
- **[decdn/android-demo](https://github.com/decdn/android-demo)** and **[decdn/ios-demo](https://github.com/decdn/ios-demo)**: one-screen phone apps built on the [`decdn-client`](https://docs.rs/decdn-client) SDK. They download a file or a whole bundle, verify every byte, and pay per MB from a sponsored pool, so the phone needs no wallet.
- **[decdn/browser-demo](https://github.com/decdn/browser-demo)**: a browser extension that opens `decdn:` links and media in any web page through a local `decdn gateway`, verifying every byte and paying per MB under a sponsor's or publisher's capability.
- **[decdn/devops](https://github.com/decdn/devops)**: deploy and operate deCDN for node operators and publishers. Docker Compose is the recommended quickstart; Ansible roles and playbooks ship as the [`decdn.node`](https://galaxy.ansible.com/ui/repo/published/decdn/node/) and [`decdn.publisher`](https://galaxy.ansible.com/ui/repo/published/decdn/publisher/) Galaxy collections, alongside cloud-init templates and a signed Helm chart on [Artifact Hub](https://artifacthub.io/packages/helm/decdn-node/decdn-node). Covers cache and origin nodes, sponsord and its onramp, iroh relays and DNS servers, Grafana monitoring, and day-2 tasks (encrypted backups, restore, host migration, decommission). Hardened and localhost-only by default; supports Debian 12/13 and Ubuntu 24.04/26.04 on x86_64 and aarch64.
- **[decdn/stats](https://github.com/decdn/stats)**: network status dashboard live at [stats.decdn.org](https://stats.decdn.org): value settled, bytes served, registered nodes, and a per-region breakdown. A Cloudflare Worker cron indexes the `FeeRouter`, `CapacityBond`, and `PaymentPool` logs on Arbitrum Sepolia into a public JSON file at `data.decdn.org`, and the static Next.js page reads it in the browser.
- **[decdn/website](https://github.com/decdn/website)**: Next.js landing page and [blog](https://decdn.org/blog), live at [decdn.org](https://decdn.org). Also holds the source for [docs.decdn.org](https://docs.decdn.org).
- **[decdn/iroh-tests](https://github.com/decdn/iroh-tests)**: reproductions for issues found in iroh, iroh-blobs, noq, and bao-tree while building deCDN. [`FEEDBACK.md`](https://github.com/decdn/iroh-tests/blob/main/FEEDBACK.md) lists every item with its test, the upstream source lines, and the workaround deCDN needed. Tests pin exact upstream releases, so a `bug_` test that starts passing after a bump means the fix landed upstream.

## For developers

- **Design first.** Every subsystem is tracked in numbered ADRs. Start with [`adr/README.md`](https://github.com/decdn/decdn/blob/main/adr/README.md) for the reading order and [`adr/architecture.md`](https://github.com/decdn/decdn/blob/main/adr/architecture.md) for the overview.
- **Rust 2024 edition, MSRV 1.99.** Tests run under `cargo nextest`. Contributions must pass `cargo fmt`, `cargo clippy`, and `cargo deny check`. See [`CONTRIBUTING.md`](https://github.com/decdn/decdn/blob/main/CONTRIBUTING.md) for environment setup.
- **Strict anti-panic policy.** Clippy denies `unwrap_used`, `expect_used`, `panic`, and `indexing_slicing` across the whole workspace. New contributors run into this most often.
- **Docs.** User and operator docs are at [docs.decdn.org](https://docs.decdn.org). To run a node, start with the [operator guide](https://docs.decdn.org/run-a-node/overview).
